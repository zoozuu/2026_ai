선형 회귀(직선)는 0과 1 사이로 제한되어야 하는 분류 문제에서 한계가 있습니다. 반면 로지스틱 회귀는 S자 곡선(시그모이드)을 사용하여 어떤 값이든 무조건 0과 1 사이의 확률로 압축해 시험 합격 가능성을 자연스럽게 예측해 줍니다!

📐 궁금한 사람만 펼쳐보는 로지스틱 회귀 산출식 원리
현재 데이터로 완성된 예측 확률 공식
P = 1 / (1 + e^-(w·x + b))
가중치(w): 계산중 | 편향(b): 계산중
1 선형 점수 (z)

z = w·x + b

공부 시간(x)에 비례하는 1차 직선 점수를 먼저 매깁니다.

2 S자 압축 (P)

P = 1 / (1 + e^-z)

점수를 0과 1 사이(0%~100%)의 확률로 깔끔하게 압축합니다.

3 50% 기준 분류

P ≥ 0.5 → 1, P < 0.5 → 0

확률이 절반(50%) 이상이면 시험 합격(1)으로 판정합니다.
