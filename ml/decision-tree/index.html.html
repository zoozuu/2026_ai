의사결정트리 실습실

먼저 동물들을 실제 트리의 가지에 옮기며 질문에 따라 집단이 계속 나뉘는 모습을 확인하고, 이어서 같은 원리로 야구 선수의 포지션을 분류합니다.

활동 방법

  1. 현재 질문을 읽고 각 대상이 예 / 아니오 중 어디에 속하는지 판단합니다.
  2. 동물은 직접 가지로 옮기고, 야구 선수는 예·아니오 버튼으로 경로를 선택합니다.
  3. 한 질문의 분류가 끝나면 그 가지 아래에 다음 질문과 새로운 가지가 이어서 생성됩니다.
