스택(Stack) 실습

스택은 나중에 들어온 데이터가 먼저 나가는 자료구조입니다.

직접 데이터를 넣고 빼면서 LIFO(Last In, First Out) 원리를 확인해 보세요.

핵심 규칙: push는 스택의 맨 위에 데이터를 넣고, pop은 맨 위의 데이터를 꺼냅니다.

스택 핵심
